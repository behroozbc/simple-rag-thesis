### Name the 4 risk categories defined in the EU AI Act and give an example for each.
Solution: The categories are
• minimal risk: e.g., games, spam filters
• limited risk: e.g., image, video generation
• high risk: significant threats to health, safety, or the fundamental rights of persons such
as uses in health, education, recruitment, critical infrastructure management, law enforcement, judiciary
• unacceptable risk: e.g., manipulate human behavior, real-time remote biometric identification in public spaces, social scoring (ranking individuals based on their personal characteristics, socio-economic status, or behavior)

### Briefly explain the difference between dynamic and static environments. Give an example for the latter.
Solution: An environment is dynamic if it can change without the agent taking an action, otherwise static. An example is an agent playing chess.

### Briefly explain the difference between fully and partially observable environments. Give an example for the latter.

Solution: An environment is fully observable if the agent knows the complete state of the environment, otherwise partially observable. An example is an agent playing a game with hidden information, such as poker.
